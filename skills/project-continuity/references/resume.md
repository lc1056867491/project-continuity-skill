# 恢复项目（resume）

仅在调用 `$project-continuity 恢复项目` 时读取本文件。此模式默认只读。

## 目标

从当前项目的管理文件恢复最小充分上下文，向用户展示状态摘要，然后等待确认或继续任务的明确指令。

## 流程

1. 确认当前工作目录和项目根目录。若目录与文档记录的项目不一致，报告冲突并停止，不跨项目操作。
2. 读取适用的项目级 `AGENTS.md`，再优先读取 `PROJECT_STATE.md` 或已有等效状态文件。
3. 根据状态文件中的当前任务和引用，按需读取项目目标、相关需求区块和关键资料索引。只加载恢复当前任务所需内容。
4. 恢复当前阶段、已完成内容、进行中任务、重要约束、未解决问题和下一步；区分已确认事实与待确认内容。
5. 输出中文恢复摘要，然后等待用户确认或发出继续任务的指令。本模式本身不修改项目文件、业务代码或配置。

不要假装拥有旧会话完整聊天记录，不根据缺失资料编造决定，也不重新设计已经由文档确认的需求。不要一次性扫描全部 PDF、图片、视频、代码或无关文件。

如果没有交接区块或状态文档，明确报告无法完整恢复的部分，再有针对性地检查少量已有管理文件能否提供背景；仍不足时列出最关键的待确认问题。缺少交接文档本身不能被描述为恢复成功。

## 恢复摘要

用中文简要包含：

- 当前项目；
- 当前阶段；
- 已确认的重要信息；
- 当前正在推进的任务；
- 未解决的问题；
- 下一步建议。

摘要后保持只读，等待用户决定是否继续。
